# 더미 (물리 엔진 할 일) — 설계

작성일: 2026-10-01 · 상태: 사용자 검토 대기 · 위치: 할 일 앱 `C:\eduReact` 의 새 탭

## 1. 목적

남은 할 일이 **공처럼 떨어져 쌓인다.** 우선순위가 높을수록 크고 무겁고, 두 번 누르면 터지면서 **실제로 끝낸 일**이 된다.
재미가 목적이지만 데이터는 진짜다 — 터뜨린 공은 할 일 목록에서도 끝낸 일이고, 되돌리기로 언제든 되살린다.

### 성공 기준

- "더미" 탭을 열면 남은 할 일 수만큼 공이 떨어져 몇 초 안에 바닥에 쌓여 멈춘다(계속 떨리지 않는다).
- 공을 끌어 던질 수 있고, 두 번 누르면 터지며 완료 처리 + "되돌리기" 토스트.
- 11개 스킨·다크 모드 모두 그 스킨 색으로 보인다.
- 키보드·화면 낭독기로도 할 일을 끝낼 수 있다. "동작 줄이기" 설정을 존중한다.
- 새 런타임 의존성 0개.

### 범위 밖 (1차)

공 모양 외의 도형, 소리, 공끼리 합치기, 더미 안에서 할 일 추가·편집(편집은 기존 상세 창으로), 끝낸 일을 공으로 보여 주기.

## 2. 무엇이 공이 되나

- 대상: `completed` 가 아니고 `archived` 가 아닌 할 일. 150개를 넘으면 앞 150개만(정렬 순서 기준), 화면 구석에 "N개 더".
- **크기**: 기준 반지름 `base = clamp(캔버스 너비 / 11, 18, 44)` px. 높음 `base × 1.0`, 보통 `× 0.78`, 낮음 `× 0.6`.
- **무게**: 반지름²(면적)에 비례.
- **떨어지는 순서**: 우선순위(높음 먼저) → 마감 빠른 순(없으면 뒤) → 원래 순서. 무거운 공이 먼저 바닥에 깔린다.
- **떨어지는 자리(가로)**: 할 일 `id` 로 정한 값(해시) — 무작위가 아니라 같은 목록이면 같은 모양으로 쌓인다.
- **색**: 우선순위 색 `--chart-1`(높음) / `--chart-2`(보통) / `--chart-3`(낮음). 지난 마감(`dueBucketOf` = overdue)은 `--high` 색 테두리(앱이 지난 마감에 쓰는 색).
- **글자**: 공 안에 제목 앞부분, 공 너비에 맞게 자르고 `…`. 글자색은 `--ink` 와 `--sheet` 중 공 색과 대비가 더 높은 쪽(그릴 때 계산).

## 3. 화면과 조작

- 탭: `TABS` 맨 뒤에 `['pile', '더미']`, 주소 `#pile`. 탭 안은 캔버스 하나(가로 꽉, 높이 = 화면 높이에서 머리글 뺀 만큼, 최소 360px).
- 탭을 열면 공이 위쪽 바깥에서 하나씩(약 80ms 간격) 떨어진다.
- 탭이 열린 동안 할 일이 **추가**되면 그 공이 새로 떨어지고, 다른 경로로 **끝내거나 지우면** 그 공은 조용히 사라진다(터지지 않음).
- **끌기**: 공을 누른 채 6px 넘게 움직이면 잡기. 잡은 공은 포인터를 따라가고, 놓으면 마지막 움직임 속도로 날아간다.
- **한 번 누르기**(움직임 6px 이하): 캔버스 아래에 카드 — 제목, 마감(오늘/내일/9/28), 우선순위, [자세히]. [자세히]는 기존 상세 창(`setDetailId`)을 연다. 빈 곳을 누르거나 Esc 로 카드 닫기.
- **두 번 누르기**(같은 공을 350ms 안에 두 번): 공이 파편 12개로 터지고(약 450ms) `TOGGLE` 로 완료. 토스트 "끝냈어요: {제목}" + [되돌리기](다시 `TOGGLE`). 되돌리면 공이 다시 떨어진다.
- 남은 할 일이 없으면 캔버스 대신 "남은 할 일이 없어요" 빈 상태.
- 탭을 떠나면 애니메이션을 멈춘다(rAF 해제). 다시 열면 처음부터 떨어진다(위치는 저장하지 않음).
- 모든 공이 멈추면(속도가 아주 작아지면) 그리기 루프도 쉰다 — 끌거나 새 공이 생기면 다시 돈다. 노트북 배터리를 위해.

## 4. 물리 (`src/lib/physics.js`, 순수 함수)

```
createWorld({ width, height, gravity })      → world
addBall(world, { id, x, y, r, vx?, vy? })     → ball   (무게 = r²)
removeBall(world, id)
step(world)                                   1/60초 한 걸음
isResting(world)                              모든 공 속도가 작으면 true
resize(world, width, height)                  벽 옮기고 밖에 있는 공은 안으로
```

- 고정 시간 간격 1/60초, 반암시적 오일러(속도 먼저, 위치 나중). 화면은 rAF 에서 흐른 시간만큼 걸음을 여러 번(최대 5번) 밟는다.
- 중력 기본 `1800 px/s²`. 바닥·좌우 벽 충돌: 반발 0.25, 바닥 마찰로 가로 속도 감쇠. 천장은 없다(위에서 떨어져 들어온다).
- 공끼리: 겹치면 무게 비율로 위치를 밀어내고(겹침 보정), 부딪히는 방향 속도에만 충격량(반발 0.2). 한 걸음에 보정 4번 반복해 쌓인 더미가 가라앉지 않게.
- 아주 느린 공은 속도를 0으로(떨림 방지).
- 모든 쌍을 검사한다 — `// ponytail: O(n²), 150개까지 충분. 넘치면 격자로 나눠 검사`.
- 같은 입력이면 같은 결과(무작위 없음).

## 5. 구성

```
src/lib/physics.js        물리 세계 (위 API) + 테스트
src/lib/pile.js           할 일 → 공 정보(id, r, 우선순위, 지난 마감, 순서, 떨어질 x 비율), 글자 자르기, 두 번 누르기 판정 + 테스트
src/components/Pile.jsx   캔버스, rAF 루프, 포인터 조작, 카드, 숨은 목록, 빈 상태
src/App.jsx               TABS 에 더미 추가, <Pile todos dispatch onOpenTodo onToast />
src/App.css               더미 탭 레이아웃·카드·숨은 목록 스타일
```

- 색은 그릴 때 `getComputedStyle` 로 스킨 토큰을 읽는다. 스킨·테마가 바뀌면 다시 읽는다(`<html>` 속성 변화 감시 또는 탭 렌더 때마다).
- 고해상도 화면: 캔버스 크기 × `devicePixelRatio`.
- 크기 변화는 `ResizeObserver` → `resize(world, …)`.

## 6. 접근성

- 캔버스는 `aria-hidden`. 그 옆에 화면에는 안 보이는(`sr-only`) 목록 — 할 일마다 "{제목} 끝내기" 버튼과 "자세히" 버튼. 초점이 가면 목록이 화면 위에 보이도록(`:focus-within` 때 sr-only 해제) 하고, 해당 공에 초점 고리를 그린다.
- 끝내기 버튼은 두 번 누르기와 같은 일(터짐 + 완료 + 되돌리기 토스트).
- `prefers-reduced-motion: reduce`: 떨어지는 장면 없이 물리를 화면 밖에서 미리 돌려 쌓인 상태로 시작, 터질 때 파편 없음, 던지기는 그대로(사용자가 직접 움직이는 것이라서).
- 터치 기기: 캔버스 `touch-action: none`(끌기가 스크롤과 싸우지 않게). 화면 크기가 작으면 공도 작아진다(`base` 가 너비 비례).

## 7. 테스트

- `physics.test.js`: 한 공이 떨어져 바닥에 닿아 멈춘다(`isResting`, y = 높이 − r), 좌우 벽 밖으로 나가지 않는다, 여러 공을 쌓아 수백 걸음 뒤 어떤 두 공도 1px 넘게 겹치지 않는다, 무거운 공이 가벼운 공을 밀어낸다(운동량), 같은 입력 → 같은 위치, `resize` 로 좁히면 공이 안으로 들어온다, `removeBall`.
